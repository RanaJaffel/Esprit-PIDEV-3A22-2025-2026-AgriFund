# AgriFund – Smart Agricultural Financing Platform

## Overview
This project was developed as part of the PIDEV – 3rd Year Engineering Program at Esprit School of Engineering (Academic Year 2025–2026).

AgriFund is a desktop application that connects farmers, banks, and administrators to manage agricultural projects, IoT data, and financial decisions.

## Features
- User Management (Admin, Farmer, Banker).
- Agricultural Project Management and ressources .
- Financial Product Management.
- IoT Data Collection (simulator).
- Financial Decision Support System.
