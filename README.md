# 🌱 AgriFund – Smart Agricultural Financing Platform

## 📌 Overview

This project was developed as part of the **PIDEV – 3rd Year Engineering Program** at **Esprit School of Engineering – Tunisia** (Academic Year 2025–2026).

AgriFund is a smart desktop platform that connects 🌾 farmers, 🏦 banks, and 👑 administrators to manage agricultural projects, IoT data, and financial decisions efficiently.

---

## 🚀 Features

- 👥 User Management (Admin, Farmer, Banker)
- 🌾 Agricultural Project Management
- 💰 Financial Products & Offers Management and ressources.
- 📡 IoT Data Management (simulator)
- 🤖 Financial Decision Support System
- 📊 Project Evaluation & Risk Analysis

---

### ⚙️ Backend

## 🏗️ Architecture

The project follows an MVC architecture:

- 📁 Controllers
- 🧠 Services
- 🗄️ Entities
- 🖥️ FXML Views
- 🔐 Session Management
- 🛢️ Database Layer
